# QR-Code Generator

Ein datenschutzfreundlicher, browserbasierter QR-Code-Generator für Links und Texte mit individueller Farbwahl, Logo-Einbettung sowie PNG- und SVG-Export.

## Datenschutz
Alle Eingaben und hochgeladenen Logos werden ausschließlich lokal im Arbeitsspeicher des Browsers verarbeitet. Beim Laden der Seite wird die Open-Source-Bibliothek `qrcode-generator` über das CDN jsDelivr eingebunden.
